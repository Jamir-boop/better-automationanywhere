## Chrome Web Store

### Summary

130 characters:

```text
50+ developer tools and improvements for Automation Anywhere: command palette, cross-Control Room copy/paste, JSON, packages & UI.
```

### Detailed description

```text
Make Automation Anywhere feel built for developers.

Better AA Developer Experience turns A360 Control Room into a faster, keyboard-first workspace. Navigate instantly, move actions between Control Rooms, inspect TaskBot JSON, manage packages, and remove everyday Bot Editor friction from one extension.

50+ TOOLS AND IMPROVEMENTS

• Command palette — Press Alt+P to search Control Room destinations, manage variables, jump to bot lines, and run developer commands without hunting through menus.

• Universal action clipboard — Copy and paste actions across Control Rooms, keep multiple local slots, transfer available capture images, and safely split large selections when Automation Anywhere's clipboard is full.

• Bot and package tools — Copy files, export bots, import TaskBot JSON, update or download package versions, and see which bots use them.

• JSON workbench — Inspect, search, replace, format, export, and save TaskBot JSON from the side panel.

• Better Bot Editor UI — Wrap long expressions and selectors, surface variable metadata and unused variables, simplify pickers, customize the canvas, and make folders easier to navigate.

• Built-in diagnostics — Run selector and API health checks and copy privacy-redacted debug logs for support.

CHROME / EDGE EXTRA

Use the optional Better Recorder localhost bridge for browser-capture workflows. Configure or disable it from Settings.

PRIVACY

Better AA does not collect or sell your data. Settings and clipboard slots stay in browser storage. The extension communicates with the Automation Anywhere Control Room you use and, when Better Recorder is enabled, a service on your own machine.

REQUIREMENTS

• Automation Anywhere A360 v40+
• Control Room language set to English
• Chrome or Edge

Independent, open-source software under the MIT License. Not affiliated with Automation Anywhere.
```
